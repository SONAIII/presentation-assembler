# Visual rhythm gate

Assembler применяет этот гейт дважды: при описании визуального направления в
deck plan и после получения рендеров собственного PPTX.

## Теги слайда

Для каждого содержательного слайда зафиксируй четыре признака:

1. **Фон:** `light`, `dark`, `accent`.
2. **Композиционный архетип:** `table`, `cards`, `timeline`, `chart`,
   `statement`, `split`, `image` или другой честный тип.
3. **Доминирующая геометрия:** `full-width`, `grid`, `split`, `single-focus`.
4. **Плотность:** `low`, `medium`, `high`.

Служебные cover/divider/closing не сравнивай с контентными слайдами.

## Метрика

Для каждой соседней пары:

`adjacent_similarity = число совпавших признаков / 4`

- Цель: `<= 0.5`, то есть соседние слайды различаются минимум по двум
  признакам.
- `0.75–1.0` допустимо только для намеренной серии или прямого сравнения.
  Причина должна быть сформулирована до сборки.
- Для дека из 4+ содержательных слайдов используй минимум два тона фона, если
  это не ухудшает читаемость данных и доступно в выбранном шаблоне.

Не меняй фон ради квоты. Разнообразие должно следовать из смены смысловой
задачи: таблица → вывод, сравнение → таймлайн, плотный анализ → крупный тезис.

## Красные флаги

- три светлых карточных слайда подряд;
- одинаковая сетка с разным текстом;
- сменился только цвет, но остались та же геометрия и плотность;
- карточки значительно выше нужного объёма текста;
- линия таймлайна короче смысловой последовательности без понятной причины.

## Как сформулировать внутреннюю правку

Формулируй через эффект для читателя, а не через внутренние названия:

- хорошо: «Слайд 3 слишком похож на слайд 2: оставь содержание, но сделай его
  тёмным single-focus с крупным выводом»;
- хорошо: «Покажи этапы линией во всю смысловую ширину, а не тремя одинаковыми
  высокими карточками»;
- плохо: «Просто перекрась карточки» — это не меняет ритм.
