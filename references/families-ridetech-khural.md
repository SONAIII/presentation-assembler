# Семейства шаблона Хурал Райдтеха — меню готовых слайдов

**12 семейств, 44 дизайнерских вариантов** (слайдов в шаблоне-доноре: 44, включая скрытую палитру атомов).

Файл генерируется: `python3 scripts/gen_families_md.py --template ridetech-khural` (правки руками перетрутся; контрактные описания — в OVERRIDES генератора). Номера слайдов (#N, 1-based) — подсказка, резолв всегда по сигнатуре (anchor), не по индексу. `structural` = всегда FILL точь-в-точь; `content_fill` = FILL с фит-политиками по слотам; GEN ✓ = у семейства есть генеративная ветка; ✓chart = данные чарта редактируются через `charts` в deckspec.

## Фото-слоты (`photos` в deckspec)
