# Custom-рецепты — Городские сервисы

Скелеты HTML-слайдов для `family: custom` шаблона Городских (когда готового
дизайнерского донора нет). Форк `custom-recipes-eda.md` под геометрию/цвета
Городских. Общая механика конвертации HTML→pptx — [custom-html.md](custom-html.md).

## Подключение

- **CSS — ИНЛАЙНОМ** в `<style>` (самодостаточный слайд, как у Еды; внешний
  `<link>` под headless `file://` НЕ грузится). `assets/gor-services/deck.css` —
  ИСТОЧНИК токенов/атомов: копируй нужный субсет в `<style>` слайда.
- **Обязательная обёртка:** `<body><div id="deck"><div class="slide">…</div></div></body>`
  — измеритель ищет `#deck` → `.slide`; без неё обмер падает («измерение не вернулось»).
- Канва `1920×1080`; корень — `<div class="slide">` (тёмный, базовый режим),
  `slide black` (чёрный), `slide white` (светлый — для аналитики/отчёта).
- Заголовок и контент клади внутри `.slide` с явной геометрией (флоу-элементы под
  `.org`-оверлеем прячутся — позиционируй `.h1` абсолютно или дай `.org` отступ сверху).
- Шрифты системные: `YS Compressed Heavy` (дисплей/значения/номера),
  `YS SemiMono Regular` (боди/лейблы). **Никакого Yango** (был багом шаблона).
- Акценты: `--red #FF1E00` (питч/энергия), `--blue #00ADFF` (аналитика),
  `--yellow #FFD700`. Один акцент на слайд.
- **Хром кастома (v2.0) — лэйауты `Title_Black` / `Title_White`** (выбор по фону
  HTML, профиль `custom-profile.json`). Оба несут **TITLE-плейсхолдер** — заголовок
  слайда верстай ТОЛЬКО классом `.h1`: движок кладёт его в плейсхолдер лэйаута
  (это и делает слайд «в шаблоне»). Боевой урок 2026-07-28: на пустых лэйаутах
  v1.0 h1 молча терялся — пустые `Empty_Black`/`Epmpty_White` хромом НЕ являются.
  Штатный футер лэйаута (`ftr idx=3`) остаётся — контент заканчивай с воздухом
  до полосы низа (см. B12).

## Карта атомов — эталоны РАЗМЕЧЕНЫ в самом шаблоне (v2.0, владелец 2026-07-29)

Дизайнер держит палитру НЕ витриной, а фигурами `atom:*` прямо на эталонных
слайдах. **Правило: стиль атома = стиль эталонной фигуры; сомневаешься — открой
слайд-эталон.** Классы deck.css сняты с их XML:

| Атом | Класс | Эталон в шаблоне | Спека |
|---|---|---|---|
| Цифра-номер в круге | `.numbox` | номера содержания **#51/#52** | круг 106×106, обводка 1.5px, цифра 60px YS Compressed |
| …активный пункт | `.numbox.active` | **#51** (разделитель) | белая заливка + чёрная цифра (fill bg1/tx1) |
| Голая крупная цифра | `.bignum` | «ХХ» **#9** (96pt), **#19** (150pt), «100%» **#35** (222pt) | YS Compressed Heavy, без подложки |
| Пилюля-подпись | `.pill` | `atom:pill` **#29** | 65px высоты, обводка 1.5px, текст 24 SemiMono |
| Орг-узел | `.org .node` | `atom:pill` **#34** | чёрная пилюля, белая обводка 2px, полное скругление |
| Линия | `.nline` / `data-line` | `atom:line` **#32** | 2px, белая (ink на светлом) |
| Стрелка | `data-line="arrow"` | `atom:arrow` **#33** | 2px + наконечник, цвет = background |

## Числа и номера — канон (правило владельца 2026-07-28)

У Городских ровно **две формы** числа/номера:

1. **Голая крупная цифра** — `.bignum`. Акцент — цветом самой цифры.
2. **Цифра в КРУГЕ-ОБВОДКЕ** — `.numbox` (как содержание #51/#52); активная
   тема разделителя — `.numbox.active` (инверсия: заливка + контрастная цифра).

**ЗАПРЕЩЕНО: залитые цветные круги/плашки-бейджи под номерами** (красные кружки
01–04 из боевого прогона GR-дека — НЕ канон) и любые изобретённые подложки.
Прежде чем рисовать «свой» атом — найди его на слайдах шаблона (см. карту выше);
нет у дизайнера → бери готовый класс из deck.css.

## Когда идём в custom (а не fill)

Донор бесполезен для 1:1-заполнения — раскладка всегда своя:
- **орг-структура** (#30 «Орден Феникса») — отделы/составы у всех разные;
- **HR-дашборд** (#43) — карточки+таблица, слишком плотная беспоко-компоновка;
- **цитаты-постеры** (#13/#14) — фразы разложены вручную по кадру;
- **микс** (#24) — тезисы+метрики+фото в уникальной компоновке.

## Рецепт: орг-структура (главный кейс)

Дерево «руководитель → отделы → люди». Карточки — `.org .node` (фото + имя +
роль), связи — ОДНИМ SVG-слоем под карточками (нативные линии конвертируются).

**Фото людей — только из материалов пользователя.**
Порядок:
1. Определи имена и роли людей структуры.
2. Используй переданные пользователем портреты; если их нет — оставь
   плейсхолдер `.ava` (тёмный квадрат).
3. Разложи узлы по уровням, соедини SVG-линиями (`stroke:#FF1E00` или `#4a4a4a`).

Скелет:
```html
<div id="deck"><div class="slide black">   <!-- обёртка #deck обязательна; CSS инлайном в <style> -->
  <div class="h1" style="position:absolute;left:58px;top:60px">Орден Феникса</div>
  <div class="org">
    <svg viewBox="0 0 1920 960">  <!-- не глубже y=960: полоса номера чиста (B12/A15) -->
      <line x1="960" y1="300" x2="360" y2="520" stroke="#4a4a4a" stroke-width="3"/>
      <line x1="960" y1="300" x2="960" y2="520" stroke="#4a4a4a" stroke-width="3"/>
      <line x1="960" y1="300" x2="1560" y2="520" stroke="#4a4a4a" stroke-width="3"/>
    </svg>
    <div class="node head" style="left:780px;top:240px">
      <img class="ava" src="ABS/albus.jpg"><div class="who">
      <span class="name">Альбус Дамблдор</span><span class="role">Руководитель</span></div>
    </div>
    <div class="node" style="left:180px;top:520px">
      <img class="ava" src="ABS/alastor.jpg"><div class="who">
      <span class="name">Аластор Грюм</span><span class="role">Оперативный отдел</span></div>
    </div>
    <!-- ...остальные узлы аналогично, left/top по уровням... -->
  </div>
</div></div>
```

Правила: аватар `.ava` 96×96 (radius 24); узел `.node` шириной 360; корень —
`.node.head` (красный). Связи рисуй ДО узлов (SVG под карточками). Не более
~9 узлов на слайд — иначе дели на два (по отделам).

## Рецепт: HR-дашборд (#43)

Левая колонка — 3 карточки метрик (`.card` + `.value` + `.label`), правая —
таблица. Таблицу лучше нативным `<table>` (конвертируется в `a:tbl`,
см. custom-html.md), карточки — `.card`.

## Рецепт: цитата-постер (#13/#14)

Крупная фраза, разложенная по кадру + мелкая подпись-источник + 1–2 фото-чипа.
Каждая строка фразы — свой `.display`-блок с `position:absolute` (как в доноре).
Акцент-стрелка/круг — `.badge`.
