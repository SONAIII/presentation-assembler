## Фото-слоты (`photos` в deckspec)

Карта сменных фото по вариантам — из поля `image_slots` спек (не руками). Ключ = имя слота в `photos`; значение = имя из пула шаблона или локальный путь. Слот без значения = passthrough (донорское фото остаётся). Геометрия и center-crop под аспект — движка; меняется только картинка.

| Семейство · вариант | Слоты |
|---|---|
| `cover` · speakers | `portrait_1` левый портрет пользователя · `portrait_2` правый портрет пользователя |
| `images` · photos3_dark | `photo_1` левое фото · `photo_2` центр · `photo_3` правое фото |
| `images` · photos3_white | `photo_1` левое фото · `photo_2` центр · `photo_3` правое фото |
| `metrics` · icons3_dark | `icon_1` иконка карточки 1 · `icon_2` иконка карточки 2 · `icon_3` иконка карточки 3 |
| `metrics` · icons3_white | `icon_1` иконка карточки 1 · `icon_2` иконка карточки 2 · `icon_3` иконка карточки 3 |
