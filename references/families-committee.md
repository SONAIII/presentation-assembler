# Семейства шаблона Комитет — меню готовых слайдов

**8 семейств, 8 дизайнерских вариантов** (слайдов в шаблоне-доноре: 8, включая скрытую палитру атомов).

Файл генерируется: `python3 scripts/gen_families_md.py --template committee` (правки руками перетрутся; контрактные описания — в OVERRIDES генератора). Номера слайдов (#N, 1-based) — подсказка, резолв всегда по сигнатуре (anchor), не по индексу. `structural` = всегда FILL точь-в-точь; `content_fill` = FILL с фит-политиками по слотам; GEN ✓ = у семейства есть генеративная ветка; ✓chart = данные чарта редактируются через `charts` в deckspec.

| Семейство | Тир | Варианты (слайд) | GEN | Что это |
|---|---|---|---|---|

## Фото-слоты (`photos` в deckspec)

Карта сменных фото по вариантам — из поля `image_slots` спек (не руками). Ключ = имя слота в `photos`; значение = имя из пула шаблона или локальный путь. Слот без значения = passthrough (донорское фото остаётся). Геометрия и center-crop под аспект — движка; меняется только картинка.

| Семейство · вариант | Слоты |
|---|---|

Контракты слотов и ограничения — в таблицах выше (колонка «Что это» + карта фото-слотов); демо-контент каждого семейства — `examples/smoke_A_text.json` / `smoke_B_data.json` / `smoke_C_photo_gen.json` (вместе покрывают все семейства). Сборочный процесс, роутинг и STOP-точки — SKILL.md.
