# Глифы инфографики — Еда

Готовые SVG для custom-слайдов (HTML-хэтч), зеркала палитры атомов шаблона
v14 (`atom:arrow` / `atom:divider` / `atom:icon-check` / `atom:icon-cross`).
Правила применения и редполитика — `references/custom-html.md`, §Инфографика.

Как использовать: вставляй СОДЕРЖИМОЕ файла инлайном в разметку слайда
(не `<img src>`, не CSS-фон — обмерщик видит только инлайн-`<svg>`).
Глифы самодостаточны: fill/stroke в атрибутах, внешний CSS не нужен.
Размер под слайд задавай атрибутами width/height (пропорции — из viewBox);
конвертер растеризует ×4, картинка выйдет чёткой в любом разумном размере.
